# AutoWallCAD — Smart Home Plan & 2D/3D CAD Studio

**AutoWallCAD** is a lightweight, zero-dependency, browser-based architectural floor plan generator, 2D CAD editor, 3D isometric walkthrough viewer, and construction BOQ estimator.

## Deploying Free on GitHub Pages
1. Create a new public repository on GitHub (e.g., `autowallcad`).
2. Upload `index.html`, `README.md`, `manifest.json`, `sw.js`, `.nojekyll`, `VERSION`, and `CHANGELOG.md` to the root of the `main` branch.
3. Go to **Settings -> Pages**, choose **Deploy from a branch -> main / (root)**, and click **Save**.
4. Share your free live GitHub Pages URL with anyone!
